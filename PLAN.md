# PLAN: CHU-117 — замерить задержку диктовки по истории

Демон после каждой диктовки дописывает строку в `~/Library/Application Support/wav2sum/dictations.jsonl` (`daemon._dictate`): `time`, `app`, `seconds`, `raw`, `text`, `style`, `language`, `command`, `translate`, `timings: {asr, llm}`. Пустые диктовки (`raw == ""`) не пишутся. Нужен скрипт только для чтения: медиана и p90 `asr` и `llm` по длине записи, языку и режиму. Цифры решают, что ускорять первым: ASR (CHU-97, CHU-122) или LLM (CHU-120 и др.).

## Допущения

- Скрипт — модуль `wav2sum/latency.py`, запуск `uv run python -m wav2sum.latency [путь]` (по умолчанию `HISTORY_PATH`). В CLI `wav2sum` подкоманду не добавляю.
- Читаю файл целиком через `load_dictations(path, limit=…)` из `history.py` (сама функция не меняется). Ничего не пишу.
- Перцентили считаю `statistics.quantiles` из stdlib (новых зависимостей нет). Таблица — plain text / Markdown, чтобы сразу вставить в комментарий Linear.
- Старые строки без `timings` или без `translate` пропускаю / считаю `translate=false`.
- Что в `timings.llm` сидит не только генерация: ожидание в очереди `llm` за summary созвона и перезагрузка модели после 10 минут простоя. Отделить из истории это нельзя (см. вопрос 3).

## Вопросы

1. **Корзины длины.** Предлагаю `< 5 с`, `5–15 с`, `15–30 с`, `≥ 30 с` (15 с — порог из CHU-122).
2. **Режимы.** Предлагаю четыре: `cleanup`, `translate`, `command` и отдельно `short` — диктовки в 1–2 слова, где LLM не вызывается и `llm ≈ 0`. Иначе они тянут медиану LLM вниз.
3. **Холодный старт.** Предлагаю колонку/строку `cold`: диктовка, перед которой > 600 с не было других (модель, скорее всего, выгружена). Перезапуски демона из истории не видны, так что это оценка.
4. **Ollama vs mlx-lm.** До CHU-107 (мерж 2026-10-26 ~23:07) LLM жила в Ollama — эти цифры не про текущую архитектуру. Предлагаю флаг `--since 2026-10-26T23:07` и печатать две таблицы: «всё» и «после mlx-lm». Или только после mlx-lm — но тогда диктовок может быть мало.
5. **Разбивка.** Отдельные таблицы по каждому измерению (длина, язык, режим) плюс итог, без перекрёстных. Плюс колонка «доля ASR в сумме» (медиана `asr / (asr + llm)`) — это прямой ответ на «что ускорять».
