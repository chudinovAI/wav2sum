# wav2sum

Класс проекта: всерьёз (личный инструмент на каждый день)
Опасные зоны (здесь руль держу сам): мои записи звонков, транскрипты, история диктовок и выученный словарь; подпись и bundle id приложения (от них зависят разрешения macOS); протокол сокета между демоном и Swift-приложением

## Цель

Krisp + Wispr Flow для macOS с единственным пользовательским интерфейсом — native GUI — и двумя явно выбранными режимами обработки. Local: Qwen3-ASR для диктовки, Gemma для чистки, Qwen или Nemotron 3.5 Transcribe 30B IQ4_NL для звонков без summary. Cloud по явному выбору в мастере приложения: Deepgram для распознавания, OpenAI для чистки/summary/глав. Созвоны можно полностью выключить в GUI, оставив диктовку. Когда созвоны включены, запись автоматическая; обработка ручная по умолчанию, либо после отдельного opt-in автоматически по успешному завершению записи. Русская, английская и смешанная речь. Закрытое распространение друзьям без SaaS/аккаунтов/общих встроенных ключей; внутренний рабочий API не подключаем.

## Критерии готовности

Каждый критерий проверяется тестом, командой или конкретным действием руками.

- [ ] Тесты и линтер проходят — `uv run pytest && uv run ruff check && uv run ruff format --check`, CI зелёный на macOS
- [ ] При включённых созвонах звонок записывается сам и останавливается после конца; обработка вручную в GUI/cloud menu-bar Summarize Last Meeting либо по отдельному auto-process opt-in. Local создаёт transcript/meta без summary, cloud также summary/главы; cloud-автоматизация требует отдельного согласия на отправку звонков.
- [ ] Cloud summary опирается только на сказанное; local не вызывает LLM для summary и не создаёт новый `summary.md`.
- [ ] Диктовка: зажать правую ⌥, сказать фразу, отпустить — текст сам вставляется в поле под курсором и остаётся в буфере обмена
- [ ] Исправление термина после вставки запоминается — руками: исправить «гитхаб» → «GitHub», продиктовать снова; `tests/test_vocabulary.py`
- [ ] Local: Qwen распознаёт диктовку; call_model выбирает Qwen (окна до 20 с) или Nemotron (до 50 с). Call ASR загружается отдельно по требованию и освобождается после успеха/ошибки; Nemotron worker закрывается/reap-ится. Cloud: Deepgram для обоих видов аудио. Проверка: tests моделей/кэша и настоящие synthetic local smoke.
- [ ] Звонки и диктовки видны в read-only native GUI. Пользовательские TUI/CLI отсутствуют; внутренние serve/setup остаются только для запуска приложения. История диктовок старше семи суток очищается при запуске daemon и ежечасно; vocabulary, edits и звонки сохраняются. Проверки: history/retention/catalog/API/native tests и GUI smoke.
- [ ] Q-1: фиксированный на сессию ограниченный контекст терминов передаётся Qwen/Deepgram/Nemotron; подсказка не разрешает выдумывать или принудительно подменять слово. Контекст ASR различается в кэше звонков.
- [ ] Q-2: LLM-чистка сохраняет смысл, факты и языковые вставки, применяет явные самокоррекции без локальных эвристических блокировок. Качество оценивается на примерах; пустой ответ и реальные ошибки не выдаются за успешную чистку.
- [ ] Q-3: cloud-диктовка начинает один HTTP upload во время речи, без повторной отправки PCM и без preview; полный ответ принимается только после последнего чанка и EOF. Local обрабатывает поступающий VAD и ограниченный изменяемый хвост, не распознаёт весь разговор заново. Финализация сохраняет контрольный хвост; отмена, disconnect и shutdown закрывают сессию без вставки позднего результата. Полнота конечной выборки не гарантирует общий WER.
- [ ] Q-4: local-звонки получают связные ограниченные фрагменты, но не смешивают говорящих и не выдают VAD-границы за word timestamps. Произнесённые самокоррекции остаются в транскрипте.
- [ ] Q-5: фактические пункты cloud summary ссылаются на существующие реплики; длинные звонки сводятся в пределах контекста с сохранением источников. Проверка ссылки не доказывает смысловую истинность пункта.
- [ ] Q-6: технические проверки и реальные локальные smoke отделены от пользовательской оценки качества/задержки и live-проверки платных API.
- [ ] Обычный standalone bundle содержит Python/runtime-зависимости/capture/совместимый FFmpeg, не зависит от checkout/venv/Xcode пользователя, не включает скачиваемые ASR/LLM/diarization weights, секреты и историю. Явный private-beta build отдельно включает введённые владельцем friend-ключи; обычная сборка их не обнаруживает и не копирует. Небольшой Silero VAD входит в runtime. Проверка: перенос bundle и isolated-home imports/audio decode. Минимальный macOS берётся из реальных Mach-O, notarization отдельно.
- [ ] Первый запуск не запускает daemon до явного Apply. Settings сохраняет выбранный app mode и модели, управляет Keychain/явными downloads/permission buttons; busy recording/dictation/loading/jobs не прерываются ради переключения.
- [ ] Settings сохраняет выключатель созвонов после Apply; отдельного конкурирующего переключателя в главном окне нет. Выключение скрывает call UI и запрещает обнаружение, запись и обработку в backend, не затрагивая диктовку, сохранённые записи/результаты и скачанные модели. Подготовка local-моделей без созвонов не требует Nemotron/pyannote. Busy/pending не прерываются; прежние настройки без выключателя сохраняют включённые созвоны. Проверка: config/backend/native регрессии и actual isolated GUI off/on.
- [ ] Главное AppKit-окно открывается после Apply и из menu bar: явные start/stop звонка, timer, manual/auto, Local/Cloud, loading/off/error, Settings и подсказка диктовки. Окно и меню используют одно состояние; pending блокирует повтор, disconnect не выдаётся за остановку. Ошибки и подтверждённый saved path видны без уведомлений. Проверка: synthetic native transitions и actual UI через AX/screenshot; реальные звонки — отдельно.
- [ ] Native Calls/Dictations показывают raw/recording/queued/running/failed/done и final/raw text; явные process/open/refresh используют backend paths и прежние guards. Snapshot не применяется после intervening event/disconnect; selection сохраняется по identity, pruning снимает удалённую строку. Диктовка показывает phase/errors/clipboard и permissions без автоматической выдачи доступов. Проверка: race/reconnect/mode/read-error fixtures и actual UI с изолированным backend.
- [ ] GUI выглядит и ведёт себя как native macOS app: системные AppKit controls/fonts/colors, понятная иерархия и один очевидный основной record action; согласованные отступы, выравнивание и плотность. Главное окно, история и Settings читаемы в light/dark и при минимальном поддерживаемом размере, без обрезанных действий. Keyboard focus/Tab и AX labels доступны; recording/loading/empty/error/disconnected различаются не только цветом. Проверка: isolated actual UI для этих состояний, screenshot/AX и пользовательский сценарий «открыть → записать/остановить → найти результат», без новых разрешений или скрытой обработки.
- [ ] Share Reviewed Examples показывает собственные тексты, Select All Shown не выбирает скрытые, правка target снимает human confirmation, отдельное согласие создаёт новый JSONL без overwrite/network/audio/calls/private metadata и без изменения источников.
- [ ] Профили 16/24/32/48 GiB помечены provisional; M4/Pro/Max не выдаются за измеренные на M5 Max. Runner сохраняет cold/warm repeats/quality/RSS/swap без текста по умолчанию; оценка clean требует отдельного эталона. Ограничения памяти/качества и внешние workload-факторы раскрыты.

## Не делаем

- Не передаём аудио или текст за пределы машины в local. Согласованный выбор app mode разрешает Deepgram ASR и OpenAI cleanup/summary; ошибки не включают fallback. LoRA-примеры только явно экспортируются в локальный файл с отдельным согласием; приложение не отправляет их на сервер или ноутбук автора.
- Windows и Linux как целевые платформы (только macOS на Apple Silicon)
- Остальные фишки Loom (CHU-103): запись экрана и камеры, ссылки и шаринг, комментарии, аналитику просмотров, голосовые заметки

## Действующие решения

- **Явный выбор.** Наличие ключей не включает Cloud. Приложение сохраняет выбранный пользователем режим и выключатель созвонов. First-run ждёт Apply, смена режима/моделей/созвонов не прерывает запись, диктовку, загрузку или jobs и не использует force-kill. История не выдаёт новых разрешений на обработку или экспорт.
- **Чистка, не переписывание.** ASR-подсказки ограничены и фиксируются на сессию; они не разрешают подставлять созвучное имя. LLM получает исходную расшифровку и явные snippets/исправления, без эвристического отклонения содержательных правок. Пустой ответ или реальная ошибка обычной чистки сохраняют raw; ошибка перевода не вставляет непереведённый текст. Отменённый результат не вставляется и не сохраняется, даже если inference уже нельзя остановить.
- **Запись отдельно от обработки.** Stop подтверждает сохранённый путь, а не успешную транскрипцию. Auto-process действует только на успешно завершившиеся новые записи, не на startup backlog. Активные, повторные, неоднозначные и частичные результаты не перезаписываются через daemon. Summarize Last Meeting выбирает собственную завершённую запись по времени начала, а не изменения результата, и не повторяет ASR готового transcript.
- **Результат и доказательство.** Ссылка summary подтверждает существование/видимость реплики, но не смысловую истинность вывода. Preview не является финальной расшифровкой, отправленный paste — подтверждённой вставкой, submitted audio — provider acknowledgement или биллингом. Synthetic/fake smoke не заменяет качество живой речи или реальную проверку API.
- **Локальные модели.** Веса готовятся явно, gated terms принимает пользователь; обычный startup не скачивает Qwen/Gemma. Модели звонка загружаются по требованию и освобождаются после обработки. Core ML-конвертер GigaAM остаётся исследовательским инструментом, не runtime-бэкендом приложения; исторический ANE-бенчмарк не обосновывает новый перенос.
- **Закрытая beta.** Обычный bundle не содержит ключей; private-beta включает только явно введённые выделенные friend-ключи в извлекаемый ресурс для частной раздачи. Ресурс не импортируется в Keychain, отказ Keychain не обходится. Локальный режим не читает ключи. Лицензии и Developer ID/notarization — отдельные условия распространения, не выполненные автоматически сборкой.

## Данные и необратимые операции

- Конфиг: `~/.config/wav2sum/config.toml`. App preferences, `dictations.jsonl`, `vocabulary.json` и `edits.jsonl`: `~/Library/Application Support/wav2sum/`. Пути записей/результатов настраиваются; GUI использует пути подключённого backend.
- Согласованная retention удаляет из dictations.jsonl только строки строго старше 7×24 часов в UTC при запуске daemon и ежечасно. Это необратимое удаление, не Корзина, включая ранее накопленную историю. Ровно cutoff, будущие, неизвестные и timezone-naive даты сохраняются.
- Cleanup работает вне dictation handler под общим с append/delete lock: atomic replace сохраняет retained bytes/order/mode. Malformed JSON/UTF-8, unsafe file или write failure не должны повредить оригинал; symlink/hardlink/non-regular history отклоняются. Vocabulary, edits, записи и результаты звонков retention не затрагивает.
- GUI не удаляет данные. Удаление TUI не меняет формат хранения, retention и существующие storage helpers; нового пользовательского удаления нет. Экспорт примеров создаёт отдельный подтверждённый text-only файл без overwrite, не меняет источники и не входит в retention.
- Изменения хранения/удаления, bundle id/подписи/Info.plist и связанных macOS permissions требуют отдельного согласования. Протокол daemon/native меняется одновременно на обеих сторонах.
